# Телефоны WhatsApp-лидов: что можно восстановить, а что нет

Проверено 10.08.2026 на боевых инстансах.

## Что происходит

WhatsApp прячет адрес чата за `@lid` — приватный идентификатор, из которого номер не
выводится. Настоящий номер иногда едет рядом, в `remoteJidAlt`, и разбор его читает
(`_wa_phone` в `adapters/channels/transports.py`).

«Иногда» здесь ключевое слово:

| Свежесть треда | У лида есть номер |
|---|---|
| активны 2 дня | **100%** |
| 3–7 дней | 46% |
| старше недели | **9%** |

Код исправен. WhatsApp начал отдавать `remoteJidAlt` недавно, поэтому новые разговоры
приходят с номером, а старые — нет.

## Почему добор не поможет

Написанный и выброшенный скрипт добора искал номера в истории Evolution и находил ноль из
258. Причина — не в нём:

- `chat/findMessages` — `remoteJidAlt` есть у **81 сообщения из 2500** (3%). В старой
  истории его нет вовсе.
- `chat/findChats` — 1899 записей, все с `@lid`, поля с номером нет.
- `chat/findContacts` — 1403 записи с настоящими номерами, но ключ у них сам номер;
  связи с `@lid` нет.

Сопоставить не по чему. Номера для 258 старых тредов недоступны через Evolution — это
свойство источника, а не наша ошибка.

## Что это значит на практике

Телефон — единственный ключ, по которому WhatsApp-разговор сшивается с тем же человеком в
Instagram и в CRM. Пока его нет, такой лид живёт отдельной карточкой.

Затронуто 258 лидов, все — из переписок старше недели. Новые не затронуты.

Что с этим можно сделать без Evolution:

- **Ничего не делать.** Со временем доля уменьшается сама: разговор оживает — приходит
  сообщение с `remoteJidAlt` — номер подставляется.
- **Сшить вручную** тех, кто важен: имя и текст переписки обычно позволяют узнать человека
  в CRM, а номер оттуда вписать в карточку.
- **Спросить Evolution.** Если в новых версиях появится сопоставление `lid` → номер,
  добор станет возможен одним проходом. Тогда стоит вернуть скрипт — он лежит в истории
  этой ветки.

## Чего делать НЕ надо

Сшивать по имени. `pushName` в WhatsApp — то, что человек сам написал в профиле; в
индонезийской базе десятки «Farhan» и «Michael», и склейка по имени соединит разных людей.
Это проверено на другом срезе: поиск лида по имени даёт по тридцать совпадений без телефона.
